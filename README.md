🌍 DRR Club Quiz Platform

An Interactive Online Quiz Platform for the Disaster Risk Reduction Club





📌 About The Project

The DRR Club Quiz Platform is a web-based quiz application developed for the Disaster Risk Reduction (DRR) Club to conduct online quizzes in an interactive, time-based, and competitive environment.

The platform allows students to register using their Gmail ID and university roll number, participate in quizzes consisting of multiple questions, and compete for top positions on the leaderboard.

The main objective is to promote awareness, knowledge, and learning about Disaster Risk Reduction through a digital assessment platform.

🎯 Project Objectives

Provide a digital platform for conducting DRR Club quizzes.

Make quiz participation simple and accessible for students.
Evaluate participants based on accuracy and response time.
Ensure fair participation through unique Gmail registration.
Allow administrators to manage quiz schedules and monitor results.
Display winners through a dedicated leaderboard dashboard.


✨ Key Features

👨‍🎓 Student Features

Student Registration: Register using Gmail ID and university roll number.
Timed Quiz: Participate in a quiz containing 10 questions.
Individual Question Timer: Each question has its own time limit.
Automatic Scoring: Scores are calculated based on correct answers and response time.
Single Submission: One Gmail ID can participate only once.
Leaderboard: View rankings based on quiz performance.
Responsive Interface: Access the platform from desktop, tablet, and mobile devices.



🛡️ Admin Features

Quiz Scheduling: Configure quiz start and end dates/times.
Question Management: Manage quiz questions and answers.
Time Management: Set individual question time limits.
Result Monitoring: Track student participation and scores.
Winner Dashboard: View rankings and identify top-performing participants.
Quiz Control: Ensure the quiz is accessible only during the configured time window.


🧠 Quiz Workflow

Student opens the DRR Club Quiz Platform.
Student enters their Gmail ID and university roll number.
System validates the registration.
Student starts the quiz during the active quiz window.
The quiz displays 10 questions with individual timers.
Student submits answers within the given time.
The system calculates the final score.
Participants are ranked based on correctness and response time.
Winners are displayed on the leaderboard dashboard.



🏆 Scoring and Ranking System
The platform evaluates participants using two major factors:
Answer Accuracy: Correct answers contribute to the participant's score.
Response Time: Faster correct responses can receive ranking preference.
The leaderboard helps identify the top-performing participants based on their overall quiz performance.


🔒 Security and Fairness
Unique Gmail-based participation.
Roll number-based student identification.
Prevention of duplicate quiz submissions.
Admin-controlled quiz availability.
Server-side validation of quiz submissions and scoring.
